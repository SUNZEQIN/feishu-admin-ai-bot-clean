# Calendar Skill

作者：sunzeqin

## 适用场景

- 创建日程。
- 查询日程。
- 邀请参会人。
- 给日程添加提醒。
- 和飞书会议能力配合创建会议安排。

## 执行原则

1. 先查帮助，不要猜命令。
2. 解析用户自然语言时间时，要明确日期、开始时间、结束时间和时区。
3. 当前默认时区是 Asia/Shanghai。
4. 参会人只给姓名时，先查通讯录或群成员拿 ID。
5. 创建成功后返回日程主题、时间、参会人。

## 常见查询

优先尝试：

```bash
lark-cli calendar --help
lark-cli contact --help
```

## 回复要求

- 成功时返回日程时间、主题、参会人和日程 ID。
- 失败时说明缺少权限、人员未匹配还是参数错误。
